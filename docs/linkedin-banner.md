# LinkedIn banner

File: `public/assets/linkedin-banner.png` (1584 × 396 px). Source: `scripts/render-assets.mjs` — run `npm run assets` to re-render after changing copy or colours.

- Light, flat design in brand colours (white background, navy logo tile, blue `#1F5BF0` accent, no gradients).
- Logo, name, headline and subline start at x = 440 px so the profile photo (bottom-left on desktop) never covers them.
- Product visual (P-204 vibration trend with a bearing-wear forecast, sample data) sits on the right.
- Key content stays inside the vertical centre band, which survives LinkedIn's mobile crop.
- Fonts render with Helvetica Neue/Arial because headless rendering has no access to Google Fonts.

Also generated: `og-image.png` (1200 × 630, social preview), `logo-transparent.png`, `logo-mark-400.png`.
