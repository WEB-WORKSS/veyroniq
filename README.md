# Veyroniq website

Marketing site and interactive product prototype for Veyroniq, an AI predictive maintenance platform in development. Live at https://www.veyroniq.site once the domain is connected.

Static site with no build step: `index.html`, `styles.css`, `app.js`, `favicon.svg`.

The interactive plant workspace uses fictional sample data generated in the browser. No data is sent or stored. The early-access form opens a pre-filled email to the address in `CONTACT_EMAIL` at the top of `app.js`.
